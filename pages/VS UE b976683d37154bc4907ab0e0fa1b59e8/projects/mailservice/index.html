mailservice

Course project for the Distributed Systems exercise (184.167, 2021W) at TU Wien.

A Java mail system with separate transfer, mailbox, and monitoring servers. Transfer servers look up mailbox servers through a hierarchical naming service over Java RMI and send usage stats to the monitoring server over UDP.

The project also explored opportunistic encryption and message integrity checks. Clients accessed their mailboxes over the network without a graphical interface.

This page describes the design. The assignment materials and implementation are not included.
